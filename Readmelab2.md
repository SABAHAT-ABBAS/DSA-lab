# Stack-Based Problem Solving Journal

## Overview
This journal contains various C++ programming exercises and examples that demonstrate fundamental and advanced concepts of **stack-based problem-solving** using a custom **Stack** class. Topics include stack operations, expression validation, infix-to-postfix conversion, and postfix evaluation.

## **Description of Key Features**

### **Example Programs**
- **Stack Implementation**: A custom stack class implementing basic operations including `Push`, `Pop`, `Peek`, and `IsEmpty`.
- **Reversing Strings**: Using a stack to reverse a given string efficiently.
- **Expression Validation**: Checking whether a given mathematical expression is fully parenthesized and valid.
- **Infix to Postfix Conversion**: Transforming standard mathematical expressions into postfix notation.
- **Postfix Evaluation**: Computing the result of a valid postfix expression using a stack.

### **Exercises**
- **Balanced Parentheses**: Implement a function to check whether an expression has balanced parentheses.
- **Complex Infix-to-Postfix Conversion**: Handling operator precedence and associativity.
- **Advanced Postfix Evaluation**: Extending the evaluation logic for additional operators.
- **Stack-Based Undo Feature**: Implementing an undo mechanism using a stack.
