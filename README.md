# Recursion Examples and Exercises

## Problem Statement
Recursion is a fundamental concept in computer science where a function calls itself to solve smaller subproblems. This repository provides a collection of recursive functions that solve mathematical and logical problems, showcasing different recursion techniques.

## Objectives
- Understand and implement recursion in C++.
- Solve mathematical problems using recursive functions.
- Learn how recursion simplifies complex problems by breaking them into smaller subproblems.
- Compare recursive and iterative approaches to problem-solving.

## Overview
This repository contains various examples and exercises related to **recursion** in C++. The provided code demonstrates different recursive algorithms, including factorial computation, number reversal, power calculation, Ackermann function, and more. 

## Files and Descriptions

### **Examples**
- **Example 3.1:** Recursive function to compute the factorial of a number.
- **Example 3.2:** A recursive function to reverse an input string.
- **Example 3.3:** A recursive function to calculate the power of a number.
- **Example 3.4:** Implementation of the Ackermann function using recursion.

### **Exercises**
- **Exercise 3.1:** Computes powers of 2 from `1` to `20` using a loop.
- **Exercise 3.2:** Calls the Ackermann function with inputs `(3,4)` and displays the result.
- **Exercise 3.3 A:** Recursively prints numbers from `n` down to `0`.
- **Exercise 3.3 B:** Computes the binomial coefficient **C(n, k)** recursively.
- **Exercise 3.3 C:** Determines whether a number is prime using recursion.

## Prerequisites
To compile and run the programs, you need:
- A C++ compiler (e.g., **g++**, **MSVC**, **Clang**)
- An IDE such as **Visual Studio**, **Code::Blocks**, or **VS Code**

## Conclusion
Recursion is a powerful tool that simplifies problem-solving by breaking down problems into smaller subproblems. This repository provides hands-on experience with recursion through practical examples and exercises. Mastering recursion will enhance problem-solving skills and improve algorithmic thinking.
